# Hasil Peta

Folder ini menyimpan gambar hasil ekspor peta untuk ditampilkan di `README.md` utama. 
Unduh atau ekspor kelima peta ini dari aplikasi (misalnya dari fitur Cetak Peta), lalu simpan di folder ini **dengan nama persis seperti di bawah** (huruf kecil, format `.png`).

| Nama berkas | Keterangan Peta |
|---|---|
| `TUTUPAN_LAHAN.png` | Peta hasil klasifikasi tutupan lahan Kabupaten Bantul |
| `NDVI.png` | Peta Normalized Difference Vegetation Index (NDVI) |
| `NDBI.png` | Peta Normalized Difference Built-up Index (NDBI) |
| `NDWI.png` | Peta Normalized Difference Water Index (NDWI) |
| `NDCI.png` | Peta Normalized Difference Chlorophyll Index (NDCI) |

Pastikan resolusi gambar cukup jelas agar legenda dan area petanya terbaca saat dirender di GitHub.
